Who this plan suits

This plan fits a WordPress site owner who wants a server of their own instead of a shared account and is comfortable working on the command line. With root access on a self-managed Cloud VPS, you choose the web server, PHP setup and database yourself, and you can configure caching and security the way your site needs.

It is less suited to someone who wants the host to handle updates, malware cleanup and backups for them. On this plan, keeping the operating system patched, the firewall configured and copies of your site stored safely are tasks you take on yourself.

What changes when you manage the server yourself

On shared hosting, the provider typically installs the web server, applies security patches and offers a control panel for domains, certificates and backups. On a self-managed VPS, you set up the software stack, keep it updated and decide how backups are made and where they are stored.

The official data does not mention a control panel, a managed backup service, snapshots, server locations or which operating systems are offered, so check those details on the provider's site before signing up. Plan for backups that live off the server itself, so a mistake or failed update does not take your only copy with it.

Resources matter more than before, because nothing is shared and nothing is tuned for you. With 1 GB of RAM, a WordPress site runs the web server, PHP and the database on the same machine, so lean plugins and page caching help keep things responsive.

How billing works on this plan

Billing is listed as USD per month; billed hourly up to the monthly price. Charges build up by the hour while the server is billed, up to the monthly price shown in the price table, which works as a cap rather than a fixed charge every month.

The listed term of 1 month is the billing cycle for that monthly cap, not a commitment. The features include a flat monthly price (no intro discount), and the price after the first cycle is the same as the starting price. See the price table on this page for the current monthly amount.

Practical setup guide

  1. STEP 1Create the server and note its IP address

    Deploy the Vultr Cloud Compute 1 GB server and choose the operating system you are comfortable administering. Write down the server's public IP address, and its IPv6 address if one is assigned. Connect over SSH and confirm you can log in before moving anything.

  2. STEP 2Install your stack and copy WordPress over

    Install a web server such as Nginx, PHP and a database server, then create an empty database for WordPress. On the old host, export the WordPress database with WP-CLI if it is available there: wp db export backup.sql. Copy the export and the site files to the new server, import the database and test the site using the server's IP or a hosts file entry while the domain still points at the old host.

  3. STEP 3Point the domain at the new server

    Once the site works on the new server, update the domain's A record to the server's IPv4 address and add an AAAA record if you use IPv6. Leave the old hosting account active until DNS has fully switched over, so visitors still reach a working site in the meantime.

  4. STEP 4Issue a TLS certificate

    After the domain resolves to the new server, install Certbot and request a certificate for your domain and its www version, replacing example.com with your own domain: sudo certbot --nginx -d example.com -d www.example.com. Then load the site over HTTPS in a browser and make sure WordPress uses HTTPS URLs in its settings.

  5. STEP 5Set up updates, a firewall and backups

    Turn on automatic security updates for the operating system and keep WordPress core, themes and plugins updated. Configure a firewall that allows only SSH, HTTP and HTTPS. Schedule regular database and file backups and copy them off the server, then test a restore so you know it works before you need it.

Frequently asked questions

  • Can a WordPress site run on 1 GB of RAM?

    The plan lists 1 GB of RAM, which has to cover the web server, PHP and the database together. A small site with page caching and a modest plugin list is a reasonable fit, while a busier site may be better served by Vultr Cloud Compute 2 GB, which lists 2 GB of RAM.

  • Is there a contract or intro discount?

    Billing is listed as billed hourly up to the monthly price, so charges build up by the hour up to the monthly cap shown in the price table. The features list a flat monthly price (no intro discount), and the term of 1 month describes the billing cycle for that cap.

  • Who handles security updates and backups?

    On a self-managed VPS, you do. That means applying operating system and software updates, configuring a firewall and keeping backups stored somewhere other than the server itself.

  • How do I check where my domain points during the move?

    From your own computer, you can check the IP address your domain currently resolves to with this command, replacing example.com with your domain: dig +short A example.com
