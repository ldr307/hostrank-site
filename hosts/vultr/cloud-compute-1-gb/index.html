What Vultr Cloud Compute 1 GB includes

Vultr lists this plan in its Cloud VPS category with 1 vCPU, 1 GB of RAM, 25 GB SSD storage and 1 TB of bandwidth. The plan is described as Regular Performance (previous-gen Intel, regular SSD).

On pricing, the listing says flat monthly price (no intro discount), and the term is 1 month. The renewal price is the same as the intro price, so the amount in the price table is the amount that applies going forward. Check the table on this page for the current figure.

Who this plan suits

This plan fits a WordPress site owner who is ready to run their own server and wants dedicated VPS resources instead of a shared account. With 1 GB of RAM and 1 vCPU, it is a modest starting size, suited to a single site or a small number of sites where you keep the software stack lean.

It is less suited to someone who wants the host to handle updates, security and backups. Because the server is self-managed, you choose and install the web server, PHP, the database and WordPress yourself, and you remain responsible for keeping them patched.

What changes when you manage the server yourself

Setup: On shared hosting, WordPress often arrives with a control panel and an installer. On a self-managed VPS, you log in over SSH with root access and build the stack: a web server such as Nginx, PHP, a database server like MySQL or MariaDB, and then WordPress. Expect to spend time on configuration before the site is ready to receive visitors.

Security updates: The operating system and every package you install need regular updates. Enabling automatic security updates for the operating system, keeping WordPress core, themes and plugins current, and running a firewall that only allows SSH, HTTP and HTTPS are the basic responsibilities you take on.

Backups: The official listing for this plan does not mention backups, snapshots, a control panel, server locations or how charges are calculated, so confirm those details with Vultr before signing up. Plan for your own backup routine either way, covering both the WordPress database and the site files, and store copies somewhere other than the server itself.

Practical setup guide

  1. STEP 1Create the server and note its IP address

    Deploy the Vultr Cloud Compute 1 GB server with the operating system you are comfortable managing. Write down its public IP address, since you will need it for SSH and for DNS later. Log in over SSH with root access and create a regular user with sudo rights for daily work.

  2. STEP 2Build the stack and move WordPress

    Install a web server such as Nginx, PHP, and MySQL or MariaDB, then create a database for WordPress. Export the database from your shared host and copy the site files to the new server, then import the database and update the configuration. Test the site using the server IP or a local hosts file entry before changing any DNS.

  3. STEP 3Point the domain at the new server

    Once the site works on the new server, update the domain's A record, and the AAAA record if you use IPv6, to the server's IP address. Keep the shared hosting account active until you confirm visitors are reaching the new server. Then check that the domain resolves to the new IP from your own computer.

  4. STEP 4Issue a TLS certificate

    After DNS points at the new server, install Certbot following its official instructions and issue a certificate for your domain and the www version. Confirm that HTTPS loads correctly and that plain HTTP redirects to HTTPS. Test automatic certificate renewal so the certificate keeps renewing without manual work.

  5. STEP 5Set up updates, a firewall and backups

    Enable automatic security updates for the operating system and keep WordPress core, themes and plugins current. Configure a firewall that only allows SSH, HTTP and HTTPS. Schedule regular backups of the database and site files, store copies off the server, and practice a restore so you know it works.

Frequently asked questions

  • Is Vultr Cloud Compute 1 GB enough for a WordPress site?

    The plan lists 1 vCPU, 1 GB of RAM, 25 GB SSD storage and 1 TB of bandwidth. That can work for a lean single WordPress site, but whether it is enough depends on your plugins, traffic and media. If you need more room, Vultr Cloud Compute 2 GB lists 2 GB of RAM and 55 GB SSD storage.

  • Will the price go up after the first month?

    The renewal price is listed as the same as the intro price, and the plan is described as flat monthly price (no intro discount). The current amount is shown in the price table.

  • Who handles security updates on this plan?

    This is a self-managed server, so you do. That includes operating system updates, the web server, PHP, the database and WordPress itself, plus firewall rules.

  • How do I export my WordPress database before moving?

    If your current host offers SSH and WP-CLI, run this from the WordPress folder: wp db export backup.sql

  • How do I add HTTPS on the new server?

    Once your domain points at the new server and you use Nginx with Certbot installed, replace example.com with your own domain and run: sudo certbot --nginx -d example.com -d www.example.com
