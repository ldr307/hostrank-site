Keeping backups, renewal dates and access organised across client sites

Backups come first. The official data does not confirm any backup or restore feature for Namecheap Stellar Plus, so an agency should plan to keep its own copies of every client site and database on storage that is separate from the hosting account, on a schedule that matches how often each site changes. Even if the provider turns out to offer something, agency-controlled copies are what allow a client site to be rebuilt elsewhere without waiting on a ticket.

Renewal dates need a single source of truth. With many client sites on one account, there is one term of 12 months to track for the hosting itself, but each client's domain registration can have its own date at its own registrar. Record the hosting renewal date, the renewal price from the table, and every domain's expiry date in one shared calendar or register, with a reminder set well before each date so that budgets and client approvals can be sorted out in time.

Access is the third area. The data does not confirm whether the plan supports separate logins for staff or delegated access for clients, so check with Namecheap before signing up if per-person credentials matter to the agency's security policy. Whatever the answer, keep a credentials register that lists, for each client, the hosting login, the registrar login, the DNS provider, the site admin account and who on the team holds each one, and update it when staff join or leave.

Troubleshooting across many client domains

A common agency mix-up is a client domain that still resolves to a previous host after a move. The nameserver check in the setup guide below shows which nameservers the domain uses right now, so it can be run for each client domain and compared against the values that the new hosting account expects. The data does not state how long a change takes to propagate, so repeat the check rather than assuming a timeline.

Another frequent report is a client saying the padlock is missing or the site loops between addresses. The header check in the setup guide shows the response headers and any redirects, which usually reveals whether the certificate is in place and whether the redirect chain ends where it should. Keep a note of which client domains have been verified this way so that the same check is not repeated unnecessarily and none are skipped.

Practical setup guide

  1. STEP 1Build and test each client site before touching DNS

    Add the client site to the hosting account and upload its files and database first, then test it using whatever preview method the host provides. Add the hosting login and the client's site admin account to the agency's credentials register at the same time. Only move on to DNS once the site works, so visitors never land on an unfinished page.

  2. STEP 2Point the client's domain at the new hosting account

    At the client's registrar or DNS provider, either switch the domain's nameservers to the ones the hosting account specifies or update the relevant DNS records to the new values. To confirm which nameservers the domain is using at any moment, replace example.com with the client's domain and run: dig +short NS example.com. Repeat the check until the result matches what the hosting account expects.

  3. STEP 3Enable an SSL certificate once the domain resolves

    The official data does not confirm that an SSL certificate is included with Namecheap Stellar Plus, so check with Namecheap how certificates are issued on this plan before signing up. Issue or enable the certificate only after the domain points at the hosting account, since issuance normally depends on the domain resolving there. To confirm HTTPS answers and see any redirects, replace example.com with the client's domain and run: curl -I https://example.com

  4. STEP 4Confirm how backups and restores work

    Ask Namecheap what host-side backups exist on this plan, how often they run and how a restore is requested, and write the answer into the agency's runbook for this account. Independently of that answer, schedule the agency's own exports of each client site and database to storage outside the hosting account. Test a restore of one site into a spare location so the process is proven before it is needed.

  5. STEP 5Record the billing details in the client register

    Note the term of 12 months, the renewal date, and the renewal price shown in the table, which is higher than the first-term price. Confirm at checkout how much was prepaid and for what period, since the billing term and prepayment depend on plan. Set a reminder ahead of the renewal date so client approvals and budgets are settled in time.
