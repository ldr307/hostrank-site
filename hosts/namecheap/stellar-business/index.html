Checking DNS and HTTPS from the Terminal

After pointing a domain at the hosting account, a quick terminal check shows whether the change is visible yet. To see which nameservers the domain uses now, run this locally and replace example.com with your own domain: dig +short NS example.com

Once the site loads, confirm that HTTPS responds and see any redirects by inspecting the response headers. Replace example.com with your own domain and run: curl -I https://example.com

If the nameservers still show the old values, the DNS change may not have spread yet, or the nameservers were not updated at the registrar. If the headers show an error or no HTTPS response, check with Namecheap how certificates are issued on this plan, since the official data does not confirm SSL details.

Practical setup guide

  1. STEP 1Connect your domain

    Point the domain to the hosting account by updating nameservers or DNS records at your registrar. The exact values come from your hosting account, so copy them from there. Afterward, run the nameserver check described above from a local terminal to see whether the change is visible.

  2. STEP 2Enable HTTPS

    The official data does not confirm SSL certificates for this plan, so check with Namecheap how HTTPS is set up before you launch. Once a certificate is active, inspect the response headers from a terminal to confirm HTTPS works and that plain HTTP redirects as expected.

  3. STEP 3Upload your static build

    Upload the output folder of your static build to the site's web root. The official data does not describe upload methods such as SSH or Git, so confirm which methods are available. Keep a local copy of each build so you can redeploy quickly if something goes wrong.

  4. STEP 4Learn how backups and restores work

    The official data does not mention backups. Ask Namecheap whether backups are taken, how often, and how a restore is requested. For static sites, your source repository and build output also act as a fallback copy.

  5. STEP 5Note the renewal date and price

    The official data lists a term of twelve months and states that the renewal price differs from the intro price. Record the renewal date in your calendar and check the renewal price in the price table so the next invoice is not a surprise.
