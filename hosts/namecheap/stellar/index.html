Practical setup guide

  1. STEP 1Point the domain at the hosting account

    After signing up, locate the nameservers or DNS records that Namecheap assigns to the account and apply them at the domain registrar. Keep the current site live until the new account is ready to serve content, so that visitors never land on an empty site. To confirm which nameservers the domain currently uses, run this on a local machine, replacing example.com with the real domain: dig +short NS example.com

  2. STEP 2Enable HTTPS once DNS resolves

    Confirm whether a certificate is part of the plan, then enable it only after the domain resolves to the new account, because issuance depends on the domain pointing at the right place. Once it is active, verify that the site responds over HTTPS and that any redirects behave as expected, replacing example.com with the real domain: curl -I https://example.com

  3. STEP 3Confirm how backups and restores work

    The official data does not confirm backups for this plan. Ask Namecheap how backups are taken, how far back they go and how a restore is requested, and record the answer in the project notes. If backups are not included, budget for a separate backup tool before the site goes live.

  4. STEP 4Record the billing details for the cost review

    Write down the renewal date, the term listed for this plan and the renewal price shown in the price table, since the renewal price is higher than the first-term price. Note the prepaid amount actually charged at checkout, because the billing term and prepayment depend on plan. Set a calendar reminder ahead of the renewal date so the higher rate is approved, or the plan reconsidered, before it takes effect.
