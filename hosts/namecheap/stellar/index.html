Practical setup guide

  1. STEP 1Build and review the site first

    Upload or build the site on the new hosting account before moving any traffic. Review it using whatever preview option the host provides. Keep the old site live until the new one is ready.

  2. STEP 2Connect the domain

    Point the domain to the new host by updating its nameservers or DNS records at the registrar, using the values the host provides. To see which nameservers the domain uses now, run this and replace example.com with the actual domain: dig +short NS example.com

  3. STEP 3Enable an SSL certificate

    Once the domain points at the new host, enable an SSL certificate for it. The official data does not confirm whether an SSL certificate is included with this plan, so check before signing up. After enabling it, confirm HTTPS works by running this with example.com replaced by the actual domain: curl -I https://example.com

  4. STEP 4Learn how backups and restores work

    Find out how backups are created and how a restore is requested or performed. The official data does not confirm backup features for this plan, so verify them before relying on the host alone. Keep an independent copy of site files and databases as well.

  5. STEP 5Record the billing details

    Note the renewal date and the renewal price for the 12 months term. Because the renewal price is higher than the intro price, add the renewal amount to the budget ahead of time. Set a reminder to review the plan before it renews.
