What the DigitalOcean Basic 2 GiB plan includes

DigitalOcean Basic 2 GiB is a Cloud VPS from DigitalOcean. The official pricing page lists it with 2 GiB of RAM and 50 GiB SSD storage.

The listed feature is a Flat monthly price (no intro discount). The term is 1 month, and the renewal price is the same as the intro price, so the price shown in the table is the price that applies when the plan renews. Check the price table on this page for the current amount.

Who this plan suits

This plan fits a WordPress site owner who has outgrown shared hosting and wants a server of their own, and who is ready to take on server administration. As a Cloud VPS, it gives you the server itself rather than a managed WordPress environment, so you choose and maintain the web server, PHP, the database and everything around them.

The 1 month term suits someone testing whether running their own server is a good fit, since the commitment is short. If you prefer not to handle updates, firewalls and backups yourself, a managed hosting plan may be a more comfortable step than a self-managed VPS.

What changes when you manage the server yourself

Setup: on shared hosting, WordPress usually runs on a stack that is already installed. On a VPS, you install and configure the web server, PHP, the database server and WordPress yourself, and you are responsible for keeping that configuration working after each change.

Security updates: the operating system and every package you install need regular patching. Plan to enable automatic security updates or set a routine for applying them, keep WordPress core, themes and plugins updated, and restrict access with a firewall that only allows the services you actually use, such as SSH, HTTP and HTTPS.

Backups: on a self-managed server, you decide what gets backed up, where copies are stored and how restores work. A sound routine covers both the WordPress files and the database, keeps copies off the server, and includes a test restore so you know the backups actually work.

What to check before signing up

The official data for this plan does not list the CPU allocation, the bandwidth allowance, the exact billing method beyond the flat monthly price and 1 month term, server locations, or any built-in backup option. Confirm these details on the DigitalOcean pricing page before signing up, especially backups, since you will need a plan for them from the first day.

Also check that 2 GiB of RAM is enough for your WordPress site, its plugins and the database running on the same server, and that 50 GiB SSD leaves room for media uploads, backups kept locally and system updates.

How the alternatives compare

DigitalOcean Basic 1 GiB lists 1 GiB of RAM and 25 GiB SSD with the same Flat monthly price (no intro discount), a 1 month term and a renewal price that is the same as the intro price. It suits a smaller WordPress site with modest traffic and plugin use.

DigitalOcean Basic 2 GiB / 2 vCPU lists 2 vCPU, 2 GiB of RAM and 60 GiB SSD, with the same flat monthly pricing note and 1 month term. It suits a site that needs the same memory as this plan but wants a stated CPU allocation and more storage.

Vultr Cloud Compute 2 GB lists 1 vCPU, 2 GB of RAM, 55 GB SSD and 2 TB of bandwidth, and Vultr Cloud Compute 2 GB / 2 vCPU lists 2 vCPU, 2 GB of RAM, 65 GB SSD and 3 TB of bandwidth. They suit readers who want the CPU and bandwidth figures stated on the pricing page.

Vultr lists its resources in GB and TB while DigitalOcean lists them in GiB, so the sizes are not directly comparable on paper. Compare the prices in the table alongside the resources each plan lists.

Practical setup guide

  1. STEP 1Create the server and note its IP address

    Create the DigitalOcean Basic 2 GiB server and choose the operating system you are comfortable maintaining. Write down the public IP address assigned to it, since your DNS records and SSH connections will use it. Connect over SSH and apply all pending system updates before installing anything else.

  2. STEP 2Install the web stack and move WordPress before touching DNS

    Install a web server, PHP and a database server, then create a database and user for WordPress. Export the database and download the site files from your shared host, then import them on the new server and update the database connection settings in the WordPress configuration. Test the site on the new server, for example through a hosts file entry on your own computer, while the live site keeps running on shared hosting.

  3. STEP 3Point the domain's A and AAAA records at the server

    Once the site works on the new server, update the domain's A record, and the AAAA record if the server has an IPv6 address, to point at the new IP. To see where the domain points right now, run this from your own computer, replacing example.com with your domain: dig +short A example.com

  4. STEP 4Issue a TLS certificate once DNS points at the server

    After the domain resolves to the new server, issue a certificate so the site loads over HTTPS. If you use Nginx with Certbot installed, run this on the server, replacing example.com with your own domain: sudo certbot --nginx -d example.com -d www.example.com

  5. STEP 5Set up security updates, a firewall and backups

    Enable automatic security updates or schedule regular patching, and set a firewall that allows only SSH, HTTP and HTTPS. Set up backups of both the WordPress files and the database, store copies off the server, and test a restore. The official data does not mention a backup option for this plan, so check what DigitalOcean offers before relying on it.

Frequently asked questions

  • Does the price change when the DigitalOcean Basic 2 GiB plan renews?

    The renewal price is the same as the intro price, and the plan is listed with a Flat monthly price (no intro discount). See the price table on this page for the amount.

  • Is 2 GiB of RAM enough for a WordPress site?

    It depends on your traffic, plugins and caching, and on the fact that the web server, PHP and the database all share the same memory. If your site is already heavy on shared hosting, the DigitalOcean Basic 2 GiB / 2 vCPU option lists the same RAM with 2 vCPU and 60 GiB SSD.

  • Will the provider install WordPress or apply security updates for me?

    This is a self-managed Cloud VPS, so plan on installing the web stack and WordPress yourself and handling operating system updates, WordPress updates and firewall rules on your own.

  • Do I get SSH and root access?

    Yes, as a self-managed server you work on it directly over SSH with administrative access, which is how you install software, apply updates and manage backups.

  • Can I keep my old shared hosting running during the move?

    Yes, and it is a sensible approach. Build and test the site on the new server first, then change DNS once it is ready, and only cancel the old hosting after the site has been confirmed working on the VPS.
