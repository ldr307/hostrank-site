What the plan includes

DigitalOcean Basic 2 GiB / 2 vCPU is listed in the Cloud VPS category. Its official resources are 2 vCPU, 2 GiB of RAM and 60 GiB SSD storage. The listed feature is "Flat monthly price (no intro discount)".

The official listing does not state a bandwidth allowance for this plan, so check the transfer allowance on the provider's pricing page before moving a busy WordPress site.

Who this plan suits

This plan fits a WordPress site owner who has outgrown shared hosting and wants a server with dedicated resources that they control. With 2 vCPU and 2 GiB of RAM, it gives room to run a web server, PHP and a database on one machine for a single site or a small group of sites.

It suits someone comfortable working over SSH, or willing to learn. As a self-managed server, it comes with SSH and root access, but that also means the owner is responsible for the software stack. The official data does not mention a control panel, a one-click WordPress installer or managed WordPress tools, so check what is available before signing up if those matter.

What changes when you manage the server yourself

On shared hosting, the host usually installs the software, patches the operating system and often runs backups. On a self-managed VPS, those tasks move to the site owner. Setup means choosing an operating system, installing a web server such as Nginx, PHP and a database, then installing WordPress and moving the site files and database.

Security updates become a routine task. The operating system, web server, PHP and database all need patches, alongside WordPress core, themes and plugins. Enabling automatic security updates in the operating system and setting up a firewall that only allows SSH, HTTP and HTTPS are common first steps.

Backups also become the owner's responsibility. The official data does not confirm whether a backup service is included with this plan, so check before signing up. Even with a provider backup option, keeping separate copies of the WordPress database and files on another machine is a sensible habit.

Billing and renewal: what to check before signing up

The plan is billed in USD per month equivalent, and the official listing notes that the billing term and prepayment depend on plan. The listed term is 1 month. Before signing up, confirm on the pricing page how this plan is charged and whether any prepayment applies.

The renewal price is the same as the intro price, in line with the listed feature "Flat monthly price (no intro discount)". The current price is shown in the price table on this page.

How it compares with similar Cloud VPS plans

DigitalOcean Basic 2 GiB is the smaller sibling, with 2 GiB of RAM and 50 GiB SSD storage, compared with 60 GiB SSD on the plan covered here. Its official listing does not state a vCPU count. Billing is the same: USD per month equivalent, with billing term and prepayment depending on plan. It can suit a lighter WordPress site where the extra listed vCPU detail and storage are less important.

Vultr Cloud Compute 2 GB lists 1 vCPU, 2 GB of RAM, 55 GB SSD storage and 2 TB of bandwidth. Vultr Cloud Compute 2 GB / 2 vCPU lists 2 vCPU, 2 GB of RAM, 65 GB SSD storage and 3 TB of bandwidth. Vultr Cloud Compute 4 GB / 2 vCPU lists 2 vCPU, 4 GB of RAM, 80 GB SSD storage and 3 TB of bandwidth. All three Vultr plans list "Regular Performance (previous-gen Intel, regular SSD)" and "flat monthly price (no intro discount)", and their billing is described as USD per month, billed hourly up to the monthly price.

In practice, the Vultr plans state a bandwidth figure, which the DigitalOcean plan's listing does not. The Vultr Cloud Compute 4 GB / 2 vCPU plan lists more RAM, which may help a WordPress site with heavier plugins or a larger database. The DigitalOcean Basic 2 GiB / 2 vCPU plan fits someone who prefers DigitalOcean's monthly-equivalent billing with 2 vCPU and 60 GiB SSD. Practical setup guide

  1. STEP 1Create the server and note its IP address

    Create the DigitalOcean Basic 2 GiB / 2 vCPU server with the operating system you plan to use, and write down its public IP address. Log in over SSH and apply all pending operating system updates before installing anything else.

  2. STEP 2Secure the server and install the WordPress stack

    Enable automatic security updates and set up a firewall that allows only SSH, HTTP and HTTPS. Then install a web server such as Nginx, PHP and a database server, and create a database and user for WordPress.

  3. STEP 3Move the WordPress files and database

    On the old shared host, export the database and download the site files. If WP-CLI is available there, run this from the WordPress folder: wp db export backup.sql. Import the database and files on the new server, then test the site before changing DNS, for example through a hosts file entry on your own computer.

  4. STEP 4Point the domain and issue a TLS certificate

    Once the site works on the new server, update the domain's A record, and the AAAA record if you use IPv6, to the server's IP address. When the domain resolves to the new server, issue a TLS certificate, for example with Certbot for Nginx, and confirm the site loads over HTTPS.

  5. STEP 5Set up backups and a maintenance routine

    Schedule regular exports of the WordPress database and archives of the site files, and copy them off the server. Check the provider's backup options as well. Keep a routine for updating WordPress core, themes and plugins alongside the operating system updates.

Frequently asked questions

  • Is DigitalOcean Basic 2 GiB / 2 vCPU a managed WordPress host?

    No. It is a self-managed Cloud VPS. The owner installs and maintains the web server, PHP, database and WordPress, and handles security updates and backups.

  • Will the price change after the first month?

    The renewal price is the same as the intro price, and the plan lists "Flat monthly price (no intro discount)". See the price table for the current amount.

  • Does the plan include automatic backups?

    The official listing does not mention backups, so plan to set up your own database and file backups and check the provider's backup options before signing up.

  • Is 2 GiB of RAM enough for WordPress?

    The plan lists 2 GiB of RAM and 2 vCPU. Whether that is enough depends on traffic, plugins and caching. A site with heavy plugins may want to compare plans that list more RAM, such as Vultr Cloud Compute 4 GB / 2 vCPU.

  • How do I check that my domain points at the new server?

    From your own computer, run this and compare the result with the server's IP address, replacing example.com with your domain: dig +short A example.com
